# ProjetoCalculadoraJavaFX
## calculadora simples • java + javafx 🖩

Um dos meus primeiros projetos utilizando Java e JavaFX foi uma calculadora simples capaz de realizar as quatro operações matemáticas básicas entre dois números:

- adição
- subtração
- multiplicação
- divisão

O principal objetivo desse projeto foi praticar o desenvolvimento de interfaces gráficas, manipulação de eventos e lógica de programação utilizando JavaFX.

Durante o desenvolvimento, pude aprimorar meus conhecimentos sobre componentes de interface, como botões, campos de texto, labels e eventos de ação, além de fortalecer minha base em programação orientada a objetos com Java.

Mesmo sendo um projeto simples, ele foi importante para meu aprendizado em desenvolvimento de aplicações desktop e na construção de sistemas com interface gráfica.
